# Comida + Poção Extra — suporte a controle

Mod de **yero_gamer** para The Witcher 3, versão **0.5.4**.

[Oficina Steam](https://steamcommunity.com/sharedfiles/filedetails/?id=3816490233) · [English](README.md)

Adiciona um espaço exclusivo de comida e um quinto espaço de poção/elixir, mantendo as quatro poções originais. Os espaços extras têm suporte a controle, seguindo os comandos originais do jogo, além de seleção pelo inventário/menu radial e atalhos remapeáveis de teclado e mouse. As seleções acompanham o save.

A instalação recomendada é pela inscrição na Oficina, sincronização e reinício do jogo. A remoção é pela desinscrição. Mantenha uma única cópia ativa. Para instalação manual de desenvolvimento, utilize somente `mods/modSlotComida`, com a outra cópia desativada.

Este repositório contém os scripts, fontes da interface, recursos compilados, testes e ferramentas portáveis de empacotamento. Os CMDs da raiz verificam/empacotam o projeto; não são instaladores. Veja [as instruções de desenvolvimento](docs/DEVELOPMENT.md).

A revisão final foi confirmada no jogo pelo autor: abertura, troca pelo inventário e persistência após salvar, fechar completamente, reabrir e carregar. Os testes automáticos usam simulações da engine. Outros mods que alterem os mesmos arquivos podem exigir combinação dos scripts.

É independente do mod [Limpeza de Loja em 7 dias](https://github.com/richardcostarocha/witcher3-shop-cleanup-7-days). Para relatar problemas, informe versões, passos, erro completo e outros mods ativos.
